# 检查清单

- 输入、数据、页面题量题号一致；总览逐项等于核验答案，未确认题明确标注。重复显示题号不串题。
- 证据引用有效且教学上相关；题设不能被说成答案证明。数字、单位、选项、公式、图例对照源文件。
- 检查 1280×800、390×844 和 36 px 字号：无页面横向溢出；表格仅内部横向滚动。
- 总览显示所有题目，手机可滚至末尾；切回题型恢复双栏及会话滚动位置。
- 点按题号/空格正确定位材料与解析；原文解析可独立滚动。触屏纵向手势不得翻页。
- 全局/逐题答案显隐、字号增减重置、单区布局、全屏及退出有效；总览始终是有意公开答案的视图。
- 键盘 Tab 可达滚动区和按钮；题型栏左右/Home/End 可切换。Esc 退出沉浸；不支持原生全屏时显示说明。
- HTML 可离线打开，图片内嵌；无必需 CDN、未渲染公式或脚本报错。
- 无实体触屏验证时，不声称已在手机或教学大屏实测。

维护脚本后运行 `python scripts/test_build.py`。这些结构/生成检查不代替浏览器交互和视觉验收。
